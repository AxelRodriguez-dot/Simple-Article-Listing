## 📌 Descripción

Una página de listado de artículos construida con HTML y CSS puro. Muestra un título principal, un separador decorativo en SVG, y tres tarjetas de artículos, cada una con una imagen, un título y una fecha. En escritorio la imagen y el texto se colocan en fila, y en móvil se apilan verticalmente. El diseño es limpio,manteniendo el espacio en blanco como elemento visual principal.
